\begin{abstract}
VLAPB evaluates personalized factor binding in vision-language-action policies. The benchmark tests whether a model can use injected user preferences selectively, respond to counterfactual preference changes, adapt to explicit updates, and remain consistent as the number of user-specific factors increases. This document provides the recommended result tables and figures for reporting VLAPB performance.
\end{abstract}
